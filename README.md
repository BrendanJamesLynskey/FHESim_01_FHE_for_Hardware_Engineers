# FHE Accelerator Simulators 01 — FHE for Hardware Engineers: CKKS as a Workload

CKKS seen from the datapath, not the proof: RNS polynomials in Zq[X]/(XN+1), how big ciphertexts and evaluation keys really are, the five primitive kernels (NTT, modular multiply-add, automorphism, base conversion, rescale), noise and levels, and why key switching dominates. Includes a live parameter calculator.

Topics: CKKS, RNS, NTT, Key switching, dnum, Evaluation keys.
